# Limitations

Installed dashboard has six finance tiles. This is its full sanitized source, not live dashboard configuration/data. Input hashes identify production source; documented edits explain export differences.

Corrected continuous replay is separate from legacy paths. Capacity/loss identification, CT/EV boundaries, dated settings, unknown gaps and terminal-stock differences qualify interpretation. Conditional ranges are not confidence intervals, guaranteed savings or proven AI benefit. Defaults are synthetic and not valid financial evidence.

Original frontend tests depended on production backups/history. They are excluded rather than copied or made meaningless self-comparisons. New portable synthetic tests cover selected current logic, not all original geometry/DOM comparisons, rendering, device writes or authenticated chat. No browser/screenshot proof is claimed. Python fixtures are constructed arithmetic data, not captured household observations.

Experimental gates: app image/packaging, cgroup CPU bandwidth and soak, private credential provisioning, trusted HA snapshot transport, honest issue-time demand forecast, full AC/DC/dated-physics mapping, correct boundary splitting, broker/security/error/UTC/retry hardening, real response validation and actual fourth-card UI/report integration. Component tests do not prove full-chain production readiness. Forecast sites/roof geometry and all private inputs are omitted. No historic forecast or saving was invented.

Manifest documentation uses a non-routable placeholder pending private repository creation. Local-source licensing remains an owner decision. Privacy scan is bounded evidence, not a guarantee of anonymity.
