Read-only monetary accounting component: no inverter energy-control service. Full collector, append-only ledger, reconstruction, settings timeline, physics and continuous corrected report code included. Export substitutes synthetic defaults, without editing the installed component.

Setup through HA integration UI, not YAML. Select your cumulative energy counters, SOC and EMS-mode sensor; configure dated tariffs, evidence and model in options. Conventional Sigen default entity names are public integration names, not verified sources for another home. All included default dates/rates/physics are illustrative; replace before interpreting money. `reviewed_inputs` is a schema enum, not proof that example physics was verified.

Corrected views retain native/parent reports. Conditional ranges are not confidence intervals or AI benefit; terminal stock has no supplier credit. Legacy modules retain their original measured-SOC gap-reset semantics, distinct from corrected persistent replay. No ledger, HA options, real calibration narrative or household-trained fits are included. See root docs.
